4. Windows RAG .md character decode failure

Project\Application>python -m main

Could not load Guava docs for RAG: 'charmap' codec can't decode byte 0x90 in position 56567: character maps to <undefined>

need to set encoding in the open call:
open(path, encoding="utf-8")

UTF8 will be made default in python 3.15 which releases in only a few fays, but explicit encoding setting is still required for older python versions when running on Windows.
