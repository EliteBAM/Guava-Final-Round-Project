# Intake CRM (mock)

A barebones legal-intake CRM. It hosts a practice's PDF templates and shows PNC (Potential New Client) records as the main app creates them. The main app uses a small REST API to create PNCs and fetch documents. It runs on this PC only.

```
npm install
npm start
```

Then open <http://127.0.0.1:3000>.
